# JARVIS 1.8 — Windows x64 portable

AI uses your selected Gemini or OpenAI connection. Qwen weights, Ollama runtime,
local LLM provider, startup loading and automatic offline fallback are removed.
Local Whisper speech recognition, Windows/Kokoro speech, hand/face detection,
SQLite memory, document storage and direct desktop commands remain available.

Gemini uses its native REST/SSE API. Test & connect checks the key and model list
without generating a reply. Check available Gemini models lets you choose a model
your key can access. Timeouts, unavailable models and quota limits give distinct
recovery messages. A successful model-list check does not guarantee chat quota.
The default is gemini-3.5-flash-lite. Free quota and billing depend on your Google
project. OpenAI needs API credit. Use your own key in the masked connection form.

The original layered globe supports drag rotation, wheel/pinch zoom through the
outer shell, reset and a white/amber color toggle. Assets load locally. The same
scene is included in the friend edition; restricted Brahma code/assets are absent.

Hand cursor movement now uses adaptive smoothing and Precise/Balanced/Fast
profiles. Leaving the frame, pausing with an open palm or changing gestures resets
the hand anchor. Returning anchors at the current pointer position without jumping.
Point with the index finger to move. Pinch to click. Raise index and middle fingers
together, then move vertically to scroll. Open palm pauses; Ctrl+Alt+G stops input.

The packaged checks use mocked cloud responses and Windows input. Real local
speech recognition/synthesis and embedded WebGL are checked separately. A live
Gemini answer still requires your key, network and available quota. New smoothing
has not yet been checked with your physical hand. Pure webcam gaze remains
experimental: the earlier physical calibration failed; head-assisted control is
available. Remote iPad access remains off pending private HTTPS pairing setup.

The friend edition contains no personal chats, documents, profile database or API
keys. New local memory stays in each Windows user's JARVIS profile. When cloud AI
is connected, chat and relevant memory/file text are sent to the selected provider.
