# JARVIS V1 for Windows x64

Compact friend distribution of application build **1.8**.

Download **jarvis-v1.zip** (481.7 MB). Extract the ZIP, run
`JARVIS-1.8-Friend-Compact-Extract.exe`, then open `JARVIS-Local-Gestures.exe`
from the resulting `JARVIS-1.8-Friend` folder. Keep the support files together.

Windows native voice and local Whisper speech recognition are included.
**jarvis-v1-kokoro-voice-pack.zip** (114.1 MB) is an optional separate British
voice pack. Close JARVIS and extract that pack into the same parent folder
containing `JARVIS-1.8-Friend`, then select Kokoro in Settings > Offline speech.

Connect your own Gemini/OpenAI key for AI chat and document analysis. No offline
language model, personal keys, saved chats or creator profile is included.

The compact archive, built-in extractor and all 3,711 core files passed integrity
checks. Packaged Windows speech, local recognition, cloud adapters, pointer logic
and original 3D globe checks passed. These checks did not use physical devices
or a live AI key. SHA-256 hashes are listed in **SHA256SUMS.txt**.
