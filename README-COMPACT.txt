JARVIS 1.8 compact friend edition - Windows x64

1. Extract this ZIP to a writable folder.
2. Run JARVIS-1.8-Friend-Compact-Extract.exe and choose an extraction folder.
3. Open the resulting JARVIS-1.8-Friend folder. Run JARVIS-Local-Gestures.exe.
4. In Settings, connect your own AI key. Windows native voice is included.

Kokoro British voice is optional: download JARVIS-1.8-Kokoro-Voice-Pack.zip,
close JARVIS and extract the voice ZIP into the same parent folder containing
JARVIS-1.8-Friend. Restart, then choose Kokoro in Settings > Offline speech.
Keep Windows native selected until that pack is installed.

Only the two Kokoro weight files are separated. Local speech recognition,
Windows voice, hand/eye detection, the 3D globe and all application libraries
remain included. No extra software is needed to extract this package. The app
uses about 1.48 GB after extraction; adding Kokoro uses another 142 MB.

This compacts the user-selected 1.8 ZIP; it does not upgrade it to 1.8.2.
